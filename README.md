## Git Commands Demonstrated

* **Initialize a Repository:** `git init`
* **Clone the Repository:** `git clone <repository-url>`
* **Check Repository Status:** `git status`
* **View Branches:** `git branch`
* **Create a New Branch:** `git switch -c feature-name`
* **Switch Branch:** `git switch main`
* **Stage Changes:** `git add .`
* **Commit Changes:** `git commit -m "commit message"`
* **Push a Branch:** `git push -u origin branch-name`
* **Pull Latest Changes:** `git pull origin main`
* **View Commit History:** `git log --oneline --graph --all`
* **Add Remote Repository:** `git remote add origin <url>`
* **View Remote Repository:** `git remote -v`
* **Manage Tags:** `git tag v1.0.1`

##  GitHub Features Demonstrated

The project demonstrates the following GitHub features:
* GitHub Repository setup & management
* Collaborator access & team contributions

* Merging branches & handling conflict resolutions
* Commit history tracking
* Releases and Tagging (`v1.0.1`)
